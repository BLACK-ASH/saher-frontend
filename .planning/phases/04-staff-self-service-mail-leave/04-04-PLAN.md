## Goal

<read_first>
- features/leave/admin-page.tsx (full file: current table structure, approve/reject/view buttons, card title, how applications data is accessed, how LeaveTypePage is rendered)

- features/leave/page.tsx (after Plan 04-03: how pagination is wired on staff page, for pattern consistency)

<acceptance_criteria>
- Status filter button group renders above the applications table: "All", "Pending", "Approved", "Rejected"
- Active filter button uses `variant="default"`, inactive use `variant="outline"`
- Filtering is client-side: `applications.data?.items?.filter(item => !statusFilter || item.status === statusFilter)`
- Local `statusFilter` state is `string | null` (null = "All")
- When filter yields no results, table shows "No leave applications found." message
- `PaginationFooter` renders below the table when `totalPages > 1`
- Card title reads "Leave Requests" (not "Pending Leave Requests")
- `pnpm lint` passes with 0 errors
</acceptance_criteria>

<action>
1. In features/leave/admin-page.tsx, add `import { PaginationFooter } from "@/components/pagination-footer"`.
2. Add `const [statusFilter, setStatusFilter] = useState<string | null>(null)`.
3. Add `import { useState } from "react"` if not already present.
4. Compute filtered data: `const filteredItems = applications.data?.items?.filter(item => !statusFilter || item.status === statusFilter) ?? []`.
5. Before the table, render filter button group:
   ```
   <div className="flex flex-wrap gap-2 px-4 py-2">
     {[{ label: "All", value: null }, { label: "Pending", value: "pending" }, { label: "Approved", value: "approved" }, { label: "Rejected", value: "rejected" }].map(({ label, value }) => (
       <Button key={label} size="sm" variant={statusFilter === value ? "default" : "outline"} onClick={() => setStatusFilter(value)}>
         {label}
       </Button>
     ))}
   </div>
   ```
6. Replace the table data source from `applications.data?.items` to `filteredItems`.
7. After the table Card closing tag, add: `{applications.data && applications.data.totalPages > 1 && <div className="flex justify-end px-4 py-4"><PaginationFooter page={applications.data.page} totalPages={applications.data.totalPages} onPageChange={(p) => { /* update page via setSearchParams or local state */ }} /></div>}`.
8. Change card title from `"Pending Leave Requests"` to `"Leave Requests"`.
9. Verify LeaveTypePage component renders correctly above the applications section (no changes needed — just confirm it works).
</action>
