- [ ] CONSTRAINT: **Read-path re-validation breaks on legacy data** — `_services/*.ts` `getX()` helpers re-parse stored MongoDB docs through `*_Final` zod schemas (e.g. `_services/bank.ts:21 getBank` → `bankSchemaFinal.parse`).
