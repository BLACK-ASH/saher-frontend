# 07-05-PLAN: Shared Trash Pattern Enforcement

## Goal
Ensure one shared trash UX pattern (TrashTabPattern) covers all soft-deletable resources.

## Tasks

### Task 1: Audit all soft-deletable resources
**read_first:**
- features/users/user-action.tsx
- features/attendance-correction/attendance-correction-view.tsx
- features/leave/leave-list.tsx (or similar)
- features/mail/mail-list.tsx (or similar)
- features/payroll/payroll-table.tsx
- services/*.api.ts for each domain

**acceptance_criteria:**
- Documented list of all resources with soft-delete: users, programs, workshops, sessions, participants, reimbursement bills, notices, attendance corrections, leave applications, mail, payroll records
- Each has `isDeleted` filter on list endpoint and `restore` endpoint

### Task 2: Wrap users list in TrashTabPattern
**read_first:**
- features/users/page.tsx
- features/users/user-action.tsx
- hooks/use-admin.ts
- components/shared/trash-tab-pattern.tsx

**acceptance_criteria:**
- `features/users/page.tsx` uses `<Tabs>` with "Active"/"Deleted" tabs
- Active tab: `useAdminUsers({ isDeleted: "false" })`
- Deleted tab: `useAdminUsers({ isDeleted: "true" })` — shows restored users
- `user-action.tsx` dropdown shows "Delete" on active, "Restore" on deleted (already has logic)
- Both tabs wrapped in `<TrashTabPattern>` for consistent empty states

### Task 3: Wrap attendance corrections in TrashTabPattern
**read_first:**
- features/attendance-correction/attendance-correction-view.tsx
- hooks/use-attendance-correction.ts
- services/attendance-correction.api.ts

**acceptance_criteria:**
- Check if attendance corrections support soft-delete (backend `isDeleted` filter)
- If yes: add tabs + `TrashTabPattern` wrapper
- If no: document "Attendance corrections use status workflow (pending/approve/reject), not soft-delete" — AUDT-05 satisfied by status pattern

### Task 4: Wrap leave applications in TrashTabPattern
**read_first:**
- features/leave/leave-list.tsx (or leave application list)
- hooks/use-leave.ts
- services/leave.api.ts

**acceptance_criteria:**
- Leave list has Active/Deleted tabs with `isDeleted` filter
- `TrashTabPattern` wrapper used
- Restore mutation calls `restoreLeave` service fn

### Task 5: Wrap mail in TrashTabPattern
**read_first:**
- features/mail/mail-list.tsx

**acceptance_criteria:**
- Mail inbox/sent has trash tab for deleted messages

### Task 6: Wrap payroll in TrashTabPattern
**read_first:**

**acceptance_criteria:**

### Task 7: Run lint/typecheck

## Verification

- `/leave` — Active/Deleted tabs
