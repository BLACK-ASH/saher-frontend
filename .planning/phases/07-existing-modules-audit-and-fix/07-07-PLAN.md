# 07-07-PLAN: Test Coverage — Money & Auth Paths

> **Realization note:** The double-submit guard lives at the UI button layer
> (`disabled={isPending}`, D-26), not in the hook as the plan assumed — React Query
> does not dedupe repeated `mutate()` calls. Genuine double-submit tests therefore
> render the dialogs. Per user decision, scope was focused to the two highest-risk
> money dialogs (HandleBill, RecordPayment) rather than all 8+ mutations; the guard

> `api-wrapper.test.ts`; the 2 pre-existing `session.test.ts` failures were fixed.
