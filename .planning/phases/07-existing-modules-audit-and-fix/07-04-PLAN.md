# 07-04-PLAN: Notifications Unseen Badge & Actions

## Goal
Ensure notification feed reliably renders action buttons (including export download links) and unseen badge stays accurate.

## Tasks

### Task 1: Verify unseen count in hook response
**read_first:**
- hooks/use-notification.ts
- services/notification.api.ts

**acceptance_criteria:**
- `useNotification` hook returns `{ data: Notification[], unseenCount: number }` (or similar)
- If backend returns `meta.unseenCount`, hook extracts and exposes it
- If no unseen count in backend, add `unseenCount` computed from `data.filter(n => !n.seen).length`
- Type exports updated

### Task 2: Render unseen badge in NotificationBox
**read_first:**
- features/notification/notification-box.tsx
- app/(main)/layout.tsx (where NotificationBox is used)

**acceptance_criteria:**
- `NotificationBox` receives `unseenCount` from hook
- CardHeader shows badge: `<Badge variant={unseenCount > 0 ? "default" : "secondary"}>{unseenCount}</Badge>` next to "Notifications" title
- Badge updates in real-time (query invalidation on read)

### Task 3: Verify action button reliability
**read_first:**
- features/notification/notification-box.tsx

**acceptance_criteria:**
- Download actions: `<a href={action.url} target="_blank" rel="noreferrer">` — already done in 06-07
- External actions: `<a target="_blank" href={action.url}>` — works
- Navigate actions: `<Link href={action.url}>` — works
- No action renders cleanly (no empty AlertAction)
- Test: trigger export → notification appears → click download → file downloads

### Task 4: Mark-as-read / seen handling
**read_first:**
- hooks/use-notification.ts
- services/notification.api.ts

**acceptance_criteria:**
- If backend supports `PATCH /api/notification/:id/read`, add `markAsRead` mutation to hook
- NotificationBox marks item as read on click (or auto on view)
- Unseen count decrements immediately

### Task 5: Run lint/typecheck
**acceptance_criteria:**
- `pnpm lint` — 0 new errors
- `pnpm build` — compiles clean

## Verification
- Login as user with unseen notifications → badge shows count
- Click notification → badge decrements
- Trigger session export (06-07) → notification with download action appears → click → file downloads
- External link action opens in new tab
- Navigate action routes internally

## Must-haves for goal-backward verification
- Unseen badge accurate and updates in real-time
- All three action types (download, external, navigate) work reliably
- No console errors on notification interactions
