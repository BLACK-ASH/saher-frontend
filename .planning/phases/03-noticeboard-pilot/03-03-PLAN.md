- Form defaults:
  - For create: `expiresAt` defaults to 7 days from today as `YYYY-MM-DD` string. Use: `const d = new Date(); d.setDate(d.getDate() + 7); d.toISOString().split("T")[0]` — per D-07
  - For edit: use `initialData.expiresAt` converted to `YYYY-MM-DD` input format. Use: `new Date(initialData.expiresAt).toISOString().split("T")[0]` — shows the stored date (backend +1 already applied)
  - `title`: empty string for create, `initialData.title` for edit
  - `description`: empty string for create, `initialData.description` for edit
- `useForm<CreateNoticeInput>({ resolver: zodResolver(createNoticeSchema), defaultValues: { ... } })`
- Submit handler `onNoticeSubmit(values: CreateNoticeInput)`:
  - Convert `expiresAt` via `dateInputToIso(values.expiresAt)` — produces ISO with IST offset
  - For create: call `addNotice.mutate(payload, { onSuccess: () => { toast.success("Notice created"); router.push("/noticeboard"); } })`
  - For edit: call `editNotice.mutate({ id: initialData!.id, data: payload }, { onSuccess: () => { toast.success("Notice updated"); router.push("/noticeboard"); } })`
  - IMPORTANT: Do NOT use the mutation response to update UI — backend returns OLD doc. Cache invalidation handles the update.
- Form layout (per D-05, clean layout):
  - `<form onSubmit={form.handleSubmit(onNoticeSubmit)} className="space-y-5 max-w-2xl">`
  - Title: Controller → Field → FieldLabel("Title") + Input + FieldError
  - Description: Controller → Field → FieldLabel("Description") + Textarea(rows={6}) + FieldError
  - Expiry Date: Controller → Field → FieldLabel("Expiry Date") + Input(type="date") + FieldError
  - Submit Button: `disabled={addNotice.isPending || editNotice.isPending}`, text "Create Notice" or "Update Notice" based on mode
