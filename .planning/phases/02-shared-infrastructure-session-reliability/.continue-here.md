## Decisions Made

| Decision | Rationale |
|----------|-----------|
| `window.location.href` over `router.push` for auth transitions | Full page reload drops stale React state and avoids proxy middleware race conditions |
| `handleSessionDeath` skips redirect on public routes | Prevents infinite redirect loop where hard nav resets the `died` flag |
| `performLogoutCleanup` → `/login` directly | Avoids unnecessary proxy bounce through `/` which redirects back to `/login` |
| `resource-list-factory` uses noop fallback for optional mutations | Avoids `@typescript-eslint/no-non-null-asserted-optional-chain` lint errors |
| `docker-compose.dev.yml` in `saher/` not `saher-frontend/` | Needs both services + nginx for production-like routing simulation |
