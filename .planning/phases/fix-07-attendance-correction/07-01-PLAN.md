The function `combineDateAndTimeToIso(date, time)` at lib/date.ts:127-132 currently does:
  return `${date}T${time}:00+05:30`;

This works when `date` is "YYYY-MM-DD" but produces garbage when `date` is already an ISO datetime string like "2025-01-15T00:00:00.000Z".

Fix: Extract the date-only portion before concatenation. Add a helper at the top of lib/date.ts:

```ts
/** Extract YYYY-MM-DD from any date-ish value. Handles "YYYY-MM-DD",
 *  ISO datetime strings ("2025-01-15T00:00:00.000Z"), and Date objects. */
export const toDateOnly = (value: string | Date): string => {
  const d = typeof value === "string" ? new Date(value) : value;
  if (Number.isNaN(d.getTime())) return String(value); // best-effort passthrough
  const p = istParts(d, {
    year: "numeric",
    month: "2-digit",
    day: "2-digit",
  });
  return `${p.year}-${p.month}-${p.day}`;
};
```

Then update `combineDateAndTimeToIso` to normalize:

```ts
export const combineDateAndTimeToIso = (
  date: string,
  time: string,
): string => {
  return `${toDateOnly(date)}T${time}:00+05:30`;
};
```

This preserves the existing behavior for "YYYY-MM-DD" inputs (passthrough) and fixes ISO datetime inputs (extracts date portion). The session-editor calls at features/program/session/session-editor.tsx:118-119,141-142 also benefit from this robustness.
