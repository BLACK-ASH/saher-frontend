## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Tampering | Double-clicked installment recording duplicate payments | mitigate | D-26 disabled+spinner during pending; no optimistic updates (hook-level test from 05-02 pins this); server accumulates only what it receives |
| T-05-04-02 | Tampering | Cumulative-amount mistake overwriting salary totals | mitigate | UI labels field "this installment" + Quirk 8 helper text; service test pins body shape (plan 05-02) |
| T-05-04-03 | Denial of Service | Accidental repeated cron runs (expensive sync op) | mitigate | Confirmation dialog + full-duration disabled state |
| T-05-04-04 | Information Disclosure | Salary data to non-admins | mitigate | Server authorize('read','payroll') (manager/user lack it) + client RoleGuard on the route |
| T-05-04-05 | Elevation | Direct URL access by manager | mitigate | RoleGuard allow can(read,"payroll") redirects to /forbidden even though group layout passes them |
| T-05-SC | Tampering | Package supply chain | accept | Zero installs |
