<objective>
Build the payroll data layer (list, per-employee history, incremental installment payment, manual cron trigger) plus the shared useUserMap hook that turns raw `user` ObjectId fields into display names across all money tables.
</objective>

<purpose>
Payroll endpoints carry three traps (incremental paidSalary, sync cron, array-typed by-id) that silently corrupt money data if ignored. This plan encodes them once, tested. useUserMap (D-32) is built here because both payroll and reimbursement tables need ID→name resolution.
</purpose>
