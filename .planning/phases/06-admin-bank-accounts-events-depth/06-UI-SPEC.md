## Spacing Scale

Declared values (multiples of 4; `--spacing: 0.25rem` = 4px base in globals.css):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, checkbox-cell padding, inline badge gap |
| sm | 8px | Compact element spacing, table cell padding, form field gap |
| md | 16px | Default element spacing, card padding, form section gap |
| lg | 24px | Section padding, dialog inner padding, grid gutter |
| xl | 32px | Layout gaps between cards/drawer sections |
| 2xl | 48px | Major section breaks within detail drawers |
| 3xl | 64px | Page-level spacing (top of directory/events pages) |

Exceptions:
- **Attendance grid checkboxes:** min interactive target 44×44px (not 24px visual box) — wrap shadcn `Checkbox` in a padded cell hit-area so fast tapping on sessions is reliable (EVNT-06).
- **Wizard (onboarding) step buttons:** keep the existing register-wizard button sizing (`features/register/user-register.tsx`) — do not re-assert spacing over a working flow (ADMN-01).

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.5 | Table cells, detail text, drawer body, roster names |
| Label | 14px | 600 | 1.4 | Form `FieldLabel`, table headers, muted helper text |
| Heading | 20px | 600 | 1.2 | Dialog/drawer titles, page subheads, card titles |
| Display | 28px | 600 | 1.2 | Page titles (directory, events level pages) |

Constraints:
- **Exactly 2 weights:** 400 (regular) + 600 (semibold). No 500/700.
- **Exactly 4 sizes:** 14, 16, 20, 28.
- Session date/time **always** rendered via `lib/date.ts` IST utilties (D-18) — 12-hour format with `+05:30` awareness; never raw browser-timezone `Date`/`Intl` in event UI (EVNT-04, EVNT-06 prefill).

## Color

Uses the existing shadcn zinc tokens in `app/globals.css` (do not introduce new hues).

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` / `--sidebar` | Page background, app shell, wizard stepper background |
| Secondary (30%) | `--card` / `--muted` / `--popover` | Directory cards, roster cards, table rows, drawer/dialog surfaces, tab active track |
| Accent (10%) | `--primary` (oklch 324 magenta/purple) | **Reserved for:** primary CTA buttons (onboard submit, save account/bank, send reminder, export, Mark All), active nav/selected states, focus ring, key link affordances that require action |
| Destructive | `--destructive` (red oklch 25 hue) | **Only** delete/offboard actions: delete user, delete program/workshop/session/participant, withdraw/reject; delete + permanent-delete buttons |

Accent reserved for: **primary action buttons and active/selected states only.** Do not use accent for: passive links, table headers, badges (badges use `--muted`/`--secondary`/`outline`/`destructive` semantically — the existing users column uses `outline` for active, `destructive` for deleted), checkbox default states, or card surfaces.

Semantic color guidance for this phase:
- **Account/bank status:** no new status colors. `--muted-foreground` for masked account numbers; `--secondary` for bank "read-only (manager)" hints.
- **Attendance grid:** a checked cell uses accent (present); unchecked uses background/`--muted`. "Mark All"/"Clear" use `outline`/`ghost` variants, not accent (they are bulk helpers, not the primary save). The primary **Save corrections** button is accent.
- **Trash tabs:** follow `TrashTabPattern` — the "deleted/deleted-only" tab uses `destructive` text only on the trash icon; tabs themselves use `--muted` inactive.

|---------|------|

### Account & Bank Details (ADMN-03, ADMN-04)
| Element | Copy |
|---------|------|
| Account edit CTA | **"Edit Account"** (drawer/dialog; `PUT /admin/account/:id`, strict partial schema) |
| Bank create/edit CTA | **"Add Bank Details"** / **"Save Bank Details"** (manager-only, `can('write'\|'update','bank')`) |
| Bank restore CTA | **"Restore Bank"** (manager restore via `PATCH /admin/bank/restore/:id`) |
| Masked display | `maskAccount` util → `•••• 1234` in **all list rows**; full number only in explicit detail view |
| **No bank delete control** | Do **not** render a bank delete affordance — no role holds `delete,bank` (always 403). RESEARCH Open Q1/A2: surface the ADMN-04 delete gap as a noted acceptance gap in the plan for the user to rule on; create/edit/update/restore only. |
| Manager-only warning | `tooltip`/muted note on bank form: **"Bank details can only be changed by managers."** (admin has `bank:read` only) |
